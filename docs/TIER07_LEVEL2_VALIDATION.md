日期：2026-11-11。基线：`c4455782ea9388d5897fc27270f42dd3786ed35d`（v6 RC）。
候选：本分支 `research/tier07-level2-validation` 的提交；相对 RC 只改
`submissions/team3/tier07/solution.py` 六行（新增 `PRE_OPTIMIZATION_LEVEL = 2`，
`_simulate()` 的 `transpile` 使用该常量）。其他 Tier、官方工具、冻结版本与最终 ZIP
均未改动。

## 1. 方法

`solve()` 内部的两条电路（QPE 主电路与相位抵消检查电路）都先按
`optimization_level=2`、官方基门 `rz,sx,x,cx`、seed 12345、`num_processes=1`
预编译，再交给 Aer。Checker 会按固定级别 1 重新编译被记录的电路，因此评分指标
是“预编译后再官方重编译”的结果。实际送入 Aer 的电路就是被 Checker 记录的电路，
没有为评分另造电路；14 个受控 U 幂、逆 QFT、测量位序、恢复流程、64/32 shots 与
哈希校验均未改变。

## 2. 数学等价

- 变换只是 Qiskit 的保酉编译；不改变逻辑电路、相位精度或测量映射。
- T7 全 15 位态矢比较（去除测量后，baseline 与 pre-L2 的官方配置编译）：
  重叠 `1.0000000000000033`，相位对齐后最大振幅差 `2.1e-13`（浮点噪声）。
- 独立 Checker 的 64-shot QPE 与 32-shot 相位抵消电路都通过，明文 SHA-256 匹配。
- 局限：一次全态矢比较 + 哈希通过，不是 15 位稠密算子的形式化证明；相位抵消
  电路未做逐列算子比较。

## 5. Simplicity 情景

官方权重 40/30/20/10，Tier 7 池 1.875 分。候选与基线相比：2Q 相同、深度降低、
总门降低、活跃位相同，因此是 **Pareto 改进**（弱支配，不恶化任何指标）。

对固定对照 best 值，share 变化为：

```
Δshare = 0.3 · best_D · (1/154 − 1/266)
       + 0.2 · best_G · (1/536 − 1/727)
```

当候选本身是 depth/gates 的最优（best_D=154、best_G=536）时取上界：
Δshare ≈ 0.179 → **最多约 +0.335 分（Tier 7 池的 17.9%）**。若其他队在 depth/gates
上更好，best 更小，收益随之降低。这是**固定对照的假设上界，不是实际得分预测**；
绝对分仍取决于所有队伍的指标。

## 6. 限制

- 只跑了 Tier 7 的隔离 Checker，未跑十关全包 Checker。
- 三个种子、一台机器；不构成失败率或跨平台保证。
- 预编译收益依赖 Qiskit 2.6.1 的具体 pass 行为，升级版本需重测。
- 未做 15 位稠密算子证明；相位抵消电路只验证了实际测量结果。
- 本结论是研究性 ACCEPT，**不授权**整合进最终提交或 ZIP；任何整合都需重跑全包
  Checker 与最终打包校验。
