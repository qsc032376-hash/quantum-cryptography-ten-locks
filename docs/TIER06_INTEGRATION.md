# Tier 6 Grover 集成与评分验证

基线为 `integration/tier05@fad1a13`，量子代码取自 `f6295ac`，直接复用基线中与 `d4f561d` 一致的 `toy_cipher_classical.py`。保留量子校准、可逆 Oracle、迭代选择和测量位序；只调整团队内导入与经典接线。没有复制量子分支的原始测量记录或私有验证器。

**官方 Checker：full，SHA-256 匹配。** 单次真实验证在临时改名团队目录中完成。观察器调用实际 `solve()`，只记录计数与资源，并核对与未修改的 Checker 的评分结果一致，不替换模拟、经典筛选或哈希逻辑。

按 shots 计共 9,728 次相位查询和 2,048 次 bit 谓词调用，合计 11,776 次。Checker 记录两条不同电路，按转译后双比特门数、再按深度选取单条评分电路；校准也参与比较，但没有成为评分电路或触发标记。官方 `oracle_calls` 字段对本关为 `null`，上表逻辑调用取自转译前的构建检查和实际 shots。

测得 64 个不同候选，64 个通过公开的首字节 `Q` 检查；共享模块筛出 1 个 checksum 匹配且可解码为 UTF-8 的结果，完整前缀与 SHA-256 各通过 1 个。只对测得并去重的候选调用共享模块，量子 Oracle 仍只检查 `Q`。即使 checksum 多解，也用完整哈希与 `QC-06: ` 前缀消歧；首批无最终匹配时最多补一批，总搜索不超过 1,024 shots，受原有时间预算约束。本次未补采样；64 个是实测数量，不是覆盖完备性的证明。

本地 Python 3.13.9、Qiskit 2.6.1、Aer 0.18.2，CPU 两线程。实际恢复与筛选 28.416 秒，Checker 求解计时含观察器为 28.499 秒；求解工作进程峰值 RSS 301.9 MiB。无超时、内存错误、`no metrics` 或复核标记。此次无需 OSC；实际覆盖和耗时仍可能随采样或运行环境变化。

25 个合成测试通过，包含位序、原采样预算、checksum 多解、完整前缀与有界补采样。Tier 1–5 实现、共用模块、官方输入和工具均与基线一致，复用其 Checker 证据。没有记录真实密钥、逐候选测量或明文。
