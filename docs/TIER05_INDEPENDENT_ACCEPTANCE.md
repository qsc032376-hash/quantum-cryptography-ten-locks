## 变更与规则审查

与基线的 Git diff 中，唯一生产代码变化是 `submissions/team3/tier05/oracle.py`；其余变化为候选的测试、夹具和报告。Tier 1–4、6–10 的实现与共享依赖、官方 Oracle/Helper、题目数据、哈希、Checker 及评分配置均未改变。Tier 5 `solution.py` 与 Diffuser 保持不变。

按公开 cipher，字节条件 `PERM(S(c XOR RC XOR mask(key))) == b` 等价于量子计算的 `mask(key) == c XOR RC XOR S⁻¹(PERM⁻¹(b))`。候选仅对公开的 Q、C 和密文字节计算比较常量；密钥相关 mask 仍由受控 X/CCX 在量子电路中计算，两个字节同时参与相位标记，辅助位反计算。`solve()` 仍运行 25 轮 Oracle + Diffuser、测量 key 寄存器，只对测得候选做公开前缀检查，再解密。审阅未发现经典预先求解、密钥枚举或存储隐藏答案。

在候选隔离快照中独立运行其 **10 项合成等价/布局测试，10/10 通过**：包含人工数据的完整 key 叠加态相位、零辅助子空间恢复、一轮 Diffuser 干涉、两字节判定及 25 轮测量布局。测试使用人工数据，不读取正式密钥或记录真实测量。该验证结合公开公式支持规则与等价性审查；不声称对任意非零工作寄存器有完整算子等价。
