## 4. 方法

沿用并扩展仿射坐标共轭：

```
E(x) = M·x XOR b,  M 由 1–4 条 CNOT 实现
块 = E† · P′ · E,  P′ = E·P·E†
```

每个块的 E/E† CNOT 成本计入门数；控制线不参与 E，控制关闭恒等。
新增两块各筛选 300 个仿射配置 × 4 种综合模式（正向/逆向 × 两种清除策略），
只用全 128 输入符号验证通过、且 256×256 算子与理想受控置换一致的候选项。

## 5. 正确性

- 四个被替换块的完整 256×256 复算子与理想受控置换最大误差
  **1.01e-13 – 1.15e-13**；逆算子同量级；padding 77–127 固定；控制 0 恒等；
- 其余八个块使用已审计缓存（`b5de82…` blob）；QFT、测量映射、shots、批次、
  经典离散对数恢复均未改；
- 官方 Tier 10 Checker：**FULL / hash match / 1 条电路 / 无 flags**，
  solve **3.306 s**，指标 36,885 / 87,930 / 105,488 / 19；
- 5 组配对种子 1000–5000：基线与候选各 **5/5 通过**，明文哈希一致。

## 6. 运行时与内存

均值：基线 **3.50 s / 95.3 MiB**，候选 **3.28 s / 94.3 MiB**；候选略快、略省。
峰值 RSS 用 20 ms 采样单进程。

## 7. Simplicity

Tier 10 池 2.625 分，权重 40/30/20/10。候选相对 v6 验收基线为**严格 Pareto**。

按“候选为各项最优”的假设上界：基线 share ≈ 0.954，候选 = 1.0，
Δ≈0.046 → **最多约 +0.12 分**；若其他队伍更优，收益更小。不是实际得分预测。

## 8. 搜索覆盖与未实施方法

## 9. 限制与风险

- 30k/25k 目标未达到；36,885 仍主要是编译期仿射包络的收益；
- 一般 M 的 E/E† 成本限制收益，只有稀疏 CNOT 网络才净赚；
- 只优化了 12 个块中的 4 个；剩余块可能还有小收益，但不足以到 30k；
- 单机、5 个种子；缓存来源已解决（见取证报告），但历史报告中的 `62b6eb`
  是 CRLF 工作区哈希，需保留解释；
