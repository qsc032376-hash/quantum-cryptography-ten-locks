## Tier 2：BB84 接收与协调

Alice 的制备由官方 Channel 提供。Bob 使用与数据无关的固定伪随机种子 20261107，
在任何 `finish()` 之前生成两条链路的全部测量基；0 表示 Z，1 表示 X。
这是可复现实验的基选择策略，不是生产密码系统的随机源。

每条链路只构造一个 Channel，调用一次 `receive_all()`，然后调用一次 `finish()`。
每个输入位置仅测量一次：Z 基直接测量，X 基先 H 再测量。电路均为 1q/1c，
由官方 Channel 将 Bob 的电路接到隐藏输入态后在 Aer 上执行。
实现从不访问 `channels.dat`、私有字段或隐藏制备细节。

披露后保留 Alice/Bob 基匹配位置。QBER 的分母仅为匹配基的公开检查位，分子为其中
不一致位数。所有公开检查位置均从协调输入排除；余下实测值保留原始位置下标，
作为 `{index: bit}` 传给官方 `reconcile`。较低 QBER 链路被选中；无检查样本、
QBER 平局、协调失败均明确报错，不重测、不尝试另一组基或暴力搜索。
同一进程的公开 `Channel.log` 若已有相关测量，恢复函数会拒绝再次创建 Channel。

### Tier 2 评分口径

官方评分使用 `Channel.log` 中 Bob 提交的测量电路，不包括隐藏输入态制备。
验证器仅统计真实 Aer 调用次数，不查看那些隐藏制备电路。
Z/X 两种实际提交电路各取一个代表转译，再按实际出现次数计算汇总。

官方基门 `rz, sx, x, cx`、优化级别 1、种子 12345 下：

- Z 测量电路不含量子门；X 测量电路为 3 门、门深 3。
- 评分选定电路：1q/1c、3 门、门深 3、含测量深度 4、双比特门 0。
- 2048 条电路总门数 3084，总双比特门数 0；此总数不是单条电路的评分指标。

## Tier 3：Deutsch–Jozsa

每条电路为 7q/6c：q0–q5 输入，q6 辅助位；辅助位 X→H 制备 |−⟩，
输入 H→一次官方 Oracle→H→qj 测量到 cj。每条电路在转译前调用官方计数器，
结果均为 1。未通过门定义或矩阵判断类型。

在理想模拟和 constant/balanced 承诺下，测量 `000000` 分类为 0，其余六位串分类为 1。
Oracle 编号 0–23 对应最终字符串从左到右的位置，不做整数转换或字符串反转。
`measurement_to_bit()` 严格检查六位测量格式；最终保留恰好 24 个二进制字符和前导零。

24 条电路按编号一次批量提交 Aer，每条 1 shot，共 24 shots、24 次 Oracle 应用。
采用 statevector，最多 2 个线程、1 个并行实验、256 MiB 模拟器内存上限。
构造、转译、执行及统计合计约 15.786156 秒。

使用相同官方基门和转译设置。计数/门深不含测量；仅汇总，不读取逐门连接来恢复密钥。

| 指标 | 结果 |

| 执行电路数 / 每条 shots | 24 / 1 |
| 总 Gate Count | 468277 |
| 总 Two-Qubit Gate Count | 187392 |
| 最大 Gate Depth | 8771 |
| 评分选定电路 Gate Count | 19497 |
| 评分选定电路 Two-Qubit Gate Count | 7808 |
| 评分选定电路 Gate Depth / 含测量深度 | 8771 / 8772 |

“评分选定”按官方优先比较双比特门数、再比较深度的规则选取，
不是把所有电路拼成一条，也不是宣称该电路门数一定是最大门数。
机器记录提供无 Oracle 编号关联的完整指标直方图，避免暴露逐 Oracle 类型信息。
官方不透明 Oracle 转译后的规模较大，会影响简洁性评分；本轮未做额外优化或重复模拟。
这不是完整官方提交评分，Tier 3 尚未完成经典解密集成。

联合验证进程峰值 RSS 约 534.156 MiB，无超时或内存不足。
Tier 3 转译给出的 backend/basis 提示涉及硬件时长/误差元数据；本次为理想无噪声模拟。

## 复现与失败处理

仓库根目录、官方版本环境下：

```bash
python -B -m unittest submissions.team3.tier02.test_solution submissions.team3.tier03.test_solution
python -B -m submissions.team3.validate_tier02_03
```

人工测试覆盖测量基、QBER 抽样分母与原始下标、平局/空样本、盲选顺序及调用次数，
以及 DJ 的六位分类、24 位串顺序、单次查询、单 shot、异常结果与经典接口待集成行为。
联合验证器先运行这些测试，随后各运行一次真实恢复；每层 120 秒预算。
失败只记录异常类型，不自动重试，避免重复测量或泄露敏感输入。
若修改验证器后只需修正报告，应使用已有安全记录，不为刷新日志而重复测量。
