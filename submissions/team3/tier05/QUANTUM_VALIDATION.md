## 结论与验证范围

**量子搜索、反计算及公开前缀验证 PASS；完整 `solve()` 待经典模块集成。**

真实搜索使用 10 个搜索位、8 个工作位、1 个比较标志，共 19 qubits；25 次 Grover
迭代，一次 Aer 执行，128 shots。本次 128/128 个结果通过公开前缀验证，只有一个
不同的实测候选，且经典检查也只调用一次。没有遍历密钥空间或检查未测量的候选。

实际密钥、测量位串、完整明文和状态向量均未记录。前缀检查仅使用官方 ToyCipher
解密公开已知文字对应的密文片段，不是完整明文解密或哈希验证。
机器记录见 [quantum_validation.json](quantum_validation.json)。

## 官方约束与参数选择

官方 README 明确必须同时检查前两字节 `QC`；只检查 `Q` 会标记多个密钥。
题目承诺这两字节唯一确定密钥，因此搜索空间 N=1024，标记数 M=1。
令 theta=asin(1/sqrt(1024))，理想成功率为 sin²((2r+1)theta)。
最优实数迭代数约 24.62865，取 r=25，理论成功率为 **99.9461244744%**。

已读官方 README、理论文档与评分规则未规定 Grover 迭代、Oracle 查询或 shots 的
固定上限；官方配置规定执行与评分转译分别最多 120 秒。本实现自行设置最多 25 轮、
128 shots，避免不必要运行；它们是本地资源预算，不是冒充的官方硬限制。
验证器要求实测前缀通过率至少 90%，也仅是本地验证条件。

单电路含 25 个相位 Oracle 块和 25 个 Diffuser。按每 shot 执行所有迭代的口径，
查询总数为 **25×128=3200**；这与一次 Aer 批次不是同一计数。
Oracle 内的字节计算、比较和反计算不另算一次完整相位查询，其开销计入实际门数。
Aer 可能复用最终态演化来生成多个 shots，不改变这里的算法查询口径。

## 可逆 Oracle

没有预制 Oracle，也没有读取隐藏密钥。本实现依据公开 `mask_gates`、`SBOX_GATES`、
`PERM`、`ROUND_CONSTANT` 构建完整可逆字节解密：

1. 工作位初始化为公开密文字节与轮常量的异或。
2. 可逆计算密钥 mask。字节 i 的左旋 3i 意味着逻辑 key bit j 映射到原位
   `(j-3i) mod 10`。
3. 按官方顺序执行两个 nibble 的 S-box。
4. 将数据线 j 全程标记为 `WORK_QUBITS[PERM[j]]`，避免 SWAP；最终工作位 j
   直接对应明文 bit j。

前两字节联合相位标记流程为：

- 计算第一字节，比较是否为 Q，将比较结果写入 flag，再反计算该字节，清空工作位。
- 计算第二字节，比较是否为 C。对 flag 做 H→精确 MCX8→H，仅在两条件同时成立时
  产生负号。
- 反计算第二字节，再逆执行第一字节比较，清空工作位与 flag。

比较器使用 Qiskit `synth_mcx_n_dirty_i15(8, relative_phase=False, action_only=False)`，
借用 6 个密钥位作为 dirty 辅助，完整恢复其值和相干性。没有使用仅 action 或允许
额外相对相位的近似捷径。人工相干态测试检查了这种借用不会破坏 Grover 干涉。

Diffuser 实现 `2|+><+|−I`：对搜索位 H/X，再执行全 10 位受控 Z，逆 X/H，
并设置全局 pi 相位以采用标准符号。MCX9 通过公开 clean 合成借用已恢复为零的
4 个工作位；结束仍为零。合成后的辅助位数来自实际返回电路，而非盲猜版本接口。

## 测量与候选接口

仅测量 key q0–q9 到 c0–c9。counts 字符串为 c9…c0，直接二进制转整数，不反转。
`recover_key()` 为 Junrui 提供整数型 10-bit 密钥接口；它执行真实量子搜索后返回结果，
不打印或缓存密钥。

`recover_key_with_diagnostics()` 额外返回安全汇总，包括 shots、成功次数和查询数。
只遍历 `counts` 中实际出现的位串，使用官方 ToyCipher 检查 `locked.json` 的公开
`known_prefix`（本实例为 `QC-05:`）。必须有唯一有效候选，且它占测量的过半，
否则明确失败，不对其他密钥做经典搜索，不自动重跑量子电路。

## 测试

23 项测试全部通过，包括 20 项人工数据/mock 单元测试，以及 3 项实际人工 Aer
测试（共 9 条人工电路）。这些测试不读取真实锁文件，不搜索真实密钥。

- 两个人工密钥、字节 0/1 的完整可逆字节变换，验证旋转、轮常量和 PERM 映射。
- 人工 QC 密文的联合标记，相干双密钥的相对负号及 dirty-key 恢复。
- 仅 Q 或仅 C 匹配不能被标记。
- 工作位和 flag 清零：已知零辅助支持上的振幅概率和为 1。
- Diffuser 在计算基态和均匀态上的标准符号及辅助清理。
- 10-bit 位序、非法输入、25 轮理论概率、电路布局与命名查询计数。
- 仅检查实测候选、唯一性/过半条件、异常结果/预算不重试、经典模块缺失和接口委托。

真实量子恢复另行执行一次：**128 shots，128 次前缀成功，实测比例 100%**。
这是有限样本结果，不代表真实算法概率等于 100%；理论值仍约 99.9461%。

## 单条实际执行与评分电路指标

实际电路按官方基门 `rz, sx, x, cx`、优化级别 1、种子 12345 转译；再按 Checker
方式对实际执行的电路做一次评分转译。这次转译不运行任何额外 shots。
两次转译的统计一致：

| 指标 | 单条评分电路 |
|---|---:|
| 搜索 qubits / 总 qubits | 10 / 19 |
| 活跃量子位 | 19 |
| Classical Bits | 10 |
| Gate Count，不含测量 | 58620 |
| Two-Qubit Gate Count | 21150 |
| Gate Depth，不含测量 | 33055 |
| Circuit Depth，含测量 | 33056 |
| 总操作数，含测量 | 58630 |

这是单条 25 轮电路的复杂度，没有乘以 shots。逻辑外层视角为 10 个 H 加 25 个
Oracle 块、25 个 Diffuser，共 60 个量子操作；这不能替代展开后的评分门数。

构造、转译、执行和候选验证约 **38.937389 秒**，评分转译约 **0.744570 秒**，
均低于各自 120 秒预算。联合验证进程峰值 RSS 为 **238.645 MiB**；模拟器设定
512 MiB 上限、2 个线程。19 位双精度状态向量本身约 8 MiB，此外还有编译和库开销。
没有内存不足、超时或真实电路重复尝试。backend/basis 提示涉及硬件时长/误差参数，
本次使用理想无噪声模拟。

门深和双比特门数明显较高，会影响相对简洁性评分；本轮优先保证合法性、正确性和
可运行性，没有声称门数最优。后续可研究保持谓词等价的公开常量优化，但不可据此
在经典端逆解或枚举真实密钥。
